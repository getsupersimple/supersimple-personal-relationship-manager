# map/ — how to walk

1. Read `CLAUDE.md` (router). 2. Open `objects/_index.md`; pick the cluster. 3. Open one card. 4. Follow its **See** link to source.
Never read all of `objects/`. Never trust a `stub` card for behaviour — go to source.

Slices (human-gated): 1 catalog, 2 object cards, 3 process cards (all written 2026-10-27) → 4 `effects/` → 5 re-verify.
`effects/` is not created until it has real content.

A card is `verified` only with `verified_on`, a commit, and `path:line` citations. Code beats comments; if they
disagree the card says so.
